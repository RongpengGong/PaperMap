# PaperMap 0.2.1（2026-11-26）

[English below](#english)

## 新功能

### 待审核可以批量处理
* 页面顶部按分类列出数量，点一下跳到对应区域。
* 「可能漏译的全文译文」按可疑页数从少到多排列；可以「全部补译」（后台逐篇，只补漏掉的段落），也可以逐条或一次性标为「不用补」，之后只有译文或 PDF 变了才会重新出现。
* 待确认的分类标签按置信度排序，可以「接受置信度 ≥ 45% 的建议」「全部接受」或「全部拒绝」。

### 导出参考图板
* 图片库「★ 我的参考图」里点「导出参考图板」，按当前筛选导出到知识库的 `figure-boards/` 文件夹：高清 PNG、可打印成 PDF 的网页 `board.html`、Obsidian 可看的 Markdown 页面。
* 每张图附上你的备注、图型、出处、DOI 和图注节选。

### 导入整份参考文献表
* 在「按编号添加」窗口里粘贴一整段参考文献表，或选择 BibTeX / RIS 文件，会自动进入参考文献模式。
* 每条先按 DOI、PMID、arXiv 编号找；没有编号的用 Crossref 书目检索对上。列出「已在库里 / 有免费全文 / 无免费全文 / 没找到」，勾选后再导入。

### 数据资源按数据集查看
* 数据资源页可以切到「按数据集」：每个登录号一行，列出哪些论文产生或引用了它，带页码；被多篇论文用到的排在前面。
* 同一数据集被多篇论文使用时，结论可能不是独立验证，可以到证据对照里记录样本是否重叠。

## 修正
* 英文 / 德文界面下，数据资源的「本研究产生 / 引用的公开数据」现在会正确翻译。

## 升级
下载 `PaperMap-macOS-AppleSilicon.zip`，解压后替换「应用程序」里的 PaperMap.app。文献库、设置和笔记在 `~/PaperMap`，不受影响。

# PaperMap 0.2.1 (2026-11-26)

## New

### Batch decisions on the Review page
* Section counts at the top jump to each part.
* "Translations that may be incomplete" are sorted by fewest suspect pages; "Patch all" queues the missing paragraphs paper by paper, and "No need" (one or all) hides an entry until the translation or PDF changes.
* Uncertain labels are sorted by confidence; accept suggestions ≥ 45%, accept all, or reject all.

### Export a reference figure board
* In the figure library under "★ My reference figures", "Export reference board" writes the current selection to `figure-boards/` in your knowledge base: high-resolution PNGs, a printable `board.html`, and a Markdown page for Obsidian.
* Each figure comes with your note, plot types, source, DOI and a legend excerpt.

### Import a whole reference list
* Paste a reference list, or choose a BibTeX / RIS file, in the "Add papers by ID" dialog.
* Each entry is matched by DOI, PMID or arXiv ID, otherwise by a Crossref bibliographic search, and shown as in library / free full text / no free full text / not found; tick the ones to import.

### Data resources by dataset
* Switch the data resources page to "By dataset": one row per accession with the papers that generated or reused it and their pages; datasets used by several papers come first.
* When several papers rely on one dataset their results may not be independent – record sample overlap in the evidence comparison.

## Fixed
* The generated / reused labels on the data resources page are now translated in the English and German interface.

## Upgrade
Download `PaperMap-macOS-AppleSilicon.zip`, unzip it and replace PaperMap.app in Applications. Your library, settings and notes in `~/PaperMap` are not affected.
